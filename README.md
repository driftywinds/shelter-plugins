My plugins for the Shelter plugin system used in discord clients like Dorion and Legcord
1) ctrlq = shut the window on pressing ctrl + q
    - paste this url [https://raw.githubusercontent.com/driftywinds/shelter-plugins/main/ctrlq/](https://raw.githubusercontent.com/driftywinds/shelter-plugins/main/ctrlq/) in the ```Add plugin``` screen to add the plugin then turn it on. Background process is still accessible from the system tray in Windows.
